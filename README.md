## 📌 Tasks Completed

### Level 1
- **Task 1 – Data Exploration and Preprocessing:** Explored dataset structure, handled missing values, performed data type conversions, and analyzed the target variable distribution.
- **Task 2 – Descriptive Analysis:** Calculated statistical measures for numerical columns and explored distributions of categorical variables (Country Code, City, Cuisines).
- **Task 3 – Geospatial Analysis:** Visualized restaurant locations using latitude/longitude and analyzed location-based rating patterns.

### Level 2
- **Task 1 – Table Booking and Online Delivery:** Analyzed table booking/online delivery availability and their impact on ratings.
- **Task 2 – Price Range Analysis:** Identified common price ranges and their correlation with average ratings.
- **Task 3 – Feature Engineering:** Engineered new features from existing columns and encoded categorical variables.

### Level 3
- **Task 1 – Predictive Modeling:** Built and evaluated regression models (Linear Regression, Decision Trees, Random Forest) to predict restaurant ratings.
- **Task 2 – Customer Preference Analysis:** Analyzed cuisine-rating relationships and identified top-performing cuisines.
- **Task 3 – Data Visualization:** Created visualizations to represent rating distributions and feature relationships.
